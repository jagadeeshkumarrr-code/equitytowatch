EQUITY CALL RADAR (MARK CLOSE EDITION) - INSTALLATION & USAGE

1. Unzip this package.
2. Upload the extracted folder to Netlify Drop (https://app.netlify.com/drop) or GitHub Pages.
3. Open the HTTPS link in Google Chrome on your Android mobile -> tap three dots (⋮) -> "Install app" or "Add to Home screen".
4. Mark as Closed Feature:
   - Each stock card now features a prominent **"❌ Mark as Closed"** button.
   - Tapping it immediately moves the stock to your **Closed** tab and pauses live price polling for that specific trade.
   - You can also tap **"📂 Reopen Call"** anytime if you re-enter the trade.
